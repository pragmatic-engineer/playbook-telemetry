# playbook-telemetry (alias: pbtop)

This repository is archived. The code moved to the playbook repository, in [crates/telemetry](https://github.com/pragmatic-engineer/playbook/tree/main/crates/telemetry): https://github.com/pragmatic-engineer/playbook

Releases now come from the playbook repository, tagged `telemetry-vX.Y.Z`. The first one is [telemetry-v0.2.0](https://github.com/pragmatic-engineer/playbook/releases/tag/telemetry-v0.2.0). The releases in this repository stay available, and version 0.1.7 is the last one published here.

The Homebrew formula and the `pbtop` alias are unchanged:

```sh
brew install pragmatic-engineer/tap/playbook-telemetry
pbtop
```

Please open issues and pull requests in the playbook repository.
